marketplace lsp
cara menjalankan:
1. extract ke c:\xampp\htdocs\marketplace
2. nyalakan apache dan mysql
3. import database.sql melalui phpmyadmin
4. buka http://localhost/marketplace/

akun:
penjual: buditani / password
pembeli: siti / password

alur pembeli:
katalog -> tambah ke keranjang -> keranjang -> checkout -> order detail -> upload bukti bayar

alur penjual:
login -> produk -> crud produk
login -> pesanan -> detail -> terima/tolak -> selesai
